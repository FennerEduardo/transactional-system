# transactional-system

Reference project for [gherkin-ai](https://github.com/FennerEduardo/gherkin-ai-cli) 3.0.0. Baseline reference: an ASP.NET Core 8 service following CQRS, with RabbitMQ messaging, generated from a single transactional feature. It is the project the other references are compared against.

The project at the repository root was generated by `ghk generate` from the specification in `features/transactional-system.feature`. The project builds, and its generated tests and runtime integration suite pass, as verified on 2026-10-06 (see [Verification](#verification)).

## Stack

| Part | Technology |
|---|---|
| Backend | ASP.NET Core 8 (C#, EF Core) |

| Architecture (configuration) | `cqrs` |

## Build and test

The commands below are the ones gherkin-ai uses to verify this stack. Run them from the repository root with the toolchain installed, or inside the official image `mcr.microsoft.com/dotnet/sdk:8.0`.

```bash
dotnet build tests/*/*.Tests.csproj -nologo -v q
dotnet test tests/*/*.Tests.csproj -nologo -v q --no-build --filter "Category!=Integration&Category!=Testcontainers"
```

Runtime integration suite (IT1–IT7: transactional outbox, idempotency under concurrency, exactly-once relay, tenant isolation, saga compensation, inbox deduplication and dead-lettering, trace propagation):

```bash
docker run -d --name ghk-pg -e POSTGRES_PASSWORD=ghk -p 5432:5432 postgres:17-alpine
docker run -d --name ghk-mq -e RABBITMQ_DEFAULT_USER=ghk -e RABBITMQ_DEFAULT_PASS=ghk -p 5672:5672 rabbitmq:4-alpine
export DATABASE_URL=postgres://postgres:ghk@localhost:5432/postgres AMQP_URL=amqp://ghk:ghk@localhost:5672
dotnet test tests/*/*.Tests.csproj -nologo --no-build --filter "Category=Integration" --logger "console;verbosity=normal"
```
